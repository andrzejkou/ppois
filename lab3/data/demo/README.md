# Демонстрационные данные

Эти CSV-файлы — стартовые шаблоны для первого запуска `warehouse_app`.
Приложение читает их, если соответствующий рабочий файл `data/<name>.csv`
ещё не создан, а затем сохраняет рабочее состояние в `data/`.

- `products.csv` — три товара с начальными остатками и штрихкодами.
- `suppliers.csv` — два поставщика.
- `supplier_contracts.csv` — действующие демонстрационные договоры.
- `employees.csv` — кладовщик, складской работник, менеджер и контролёр качества.
- `customers.csv` — два покупателя.
- `sales_orders*.csv` — пустой реестр заказов и строк заказов.
- `purchase_requests*.csv` — пустой реестр заявок и строк заявок.
- `purchase_orders*.csv` — пустой реестр закупочных заказов и строк.
- `delivery_notes*.csv` — пустой реестр накладных и строк поставки.
- `receipt_history.csv` — пустая история приёмок.
- `stock_lots.csv` — пустой реестр партий.

Не редактируйте эти файлы для изменения текущего состояния после первого запуска:
для этого используйте меню приложения или удалите рабочие `data/*.csv` с помощью
`tools/reset_demo_data.sh`, чтобы снова загрузить демонстрационный набор.
