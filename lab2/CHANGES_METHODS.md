# Дополнение предметной логики

Этот пакет объединяет предыдущие изменения по ассоциациям и расписанию с дополнительными методами сотрудников, деканата и бухгалтерии.

## Ассоциации
- Teacher — Subject: преподаватель хранит назначенные дисциплины.
- Student — Submission: студент хранит работы и результаты их сдачи.
- Student — StudentApplication: студент подаёт и обрабатывает заявления.
- Student — ScholarshipApplication: студент подаёт и разрешает заявки на стипендию.
- DeanOffice — Specialty: деканат регистрирует и хранит специальности.
- AccountingDepartment — Student: бухгалтерия принимает объект студента при регистрации платежа и подсчёте выплат; записи платежей продолжают хранить studentId.

## Студенты и группы
- Student: поиск оценок по дисциплине, средняя оценка по дисциплине, удаление оценок дисциплины, подсчёт оценок ниже порога, хранение работ и заявлений.
- Group: проверка вместимости, поиск студентов, подсчёт по подгруппам, назначение подгрупп, сортировка.
- DeanOffice: поиск студента, проверка наличия, проверка мест, удаление пустой группы, определение группы студента, подсчёт задолженностей.
- Curator: проверка курирования, подсчёт студентов и задолженностей, средний балл группы, подсчёт по подгруппам, удаление студента из курируемой копии группы.

## Расписание
- Day: удаление занятия, поиск преподавателя/дисциплины, проверка пересечения времени, выборка занятий преподавателя.
- Week: удаление и поиск дня, подсчёт дней, поиск преподавателя, проверка пересечений.
- Schedule: удаление и поиск недели, подсчёт недель, получение номеров недель, поиск преподавателя, проверка пересечений.

## Преподаватели
- Teacher: назначение и удаление дисциплины, проверка преподавания дисциплины, подсчёт дисциплин и зачётных единиц.

## Бухгалтерия
- PaymentRecord: изменение суммы и назначения платежа с проверкой корректности.
- AccountingDepartment: подсчёт оплаченных сумм по студенту, общей неоплаченной суммы, погашение неоплаченных записей студента, удаление неоплаченных записей, поиск платежа, получение платежей студента.

## Проверка
Проект собирается командой:

```bash
cmake -S . -B build-check -DCMAKE_BUILD_TYPE=Debug
cmake --build build-check --clean-first -j2
```

Проверка сборки не заменяет unit-тесты и измерение покрытия.
