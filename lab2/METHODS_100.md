# Реестр содержательных методов — lab2

Консервативный рабочий реестр: **100 методов-кандидатов**. Он включает 85 ранее выделенных методов и 15 новых предметных операций из этого пакета. Конструкторы, деструкторы, геттеры, простые сеттеры и форматированный вывод не учитываются.

## 15 новых методов

| Класс | Метод | Назначение |
|---|---|---|
| `Student` | `assignBenefit()` | Назначает студенту льготу, проверяя отсутствие уже назначенной льготы и фиксируя ID студента в объекте льготы. |
| `Student` | `removeBenefit()` | Снимает назначенную льготу; операция отклоняется, если льготы нет. |
| `Student` | `recalculateAcademicDebtCount()` | Пересчитывает число дисциплин с неудовлетворительными оценками по заданному проходному порогу. |
| `DeanOffice` | `assignCuratorToGroup()` | Находит сотрудника-куратора и назначает ему существующую группу. |
| `DeanOffice` | `mergeGroups()` | Объединяет группы одной специальности при достаточной вместимости и отсутствии дублирующихся студентов. |
| `DeanOffice` | `promoteEligibleStudents()` | Переводит на следующий курс студентов группы без задолженностей и с требуемым средним баллом. |
| `Teacher` | `removeCourse()` | Удаляет ранее назначенный курс преподавателя. |
| `Teacher` | `replaceCourse()` | Заменяет назначенный курс, не допуская пустого или повторяющегося названия. |
| `Teacher` | `clearTeachingAssignments()` | Сбрасывает назначенные курсы и дисциплины преподавателя. |
| `Curator` | `assignUnassignedStudentsToSubGroup()` | Распределяет студентов без подгруппы в указанную подгруппу. |
| `Curator` | `reassignStudentsWithDebts()` | Переводит студентов с академическими задолженностями в выделенную подгруппу для дополнительной работы. |
| `AccountingDepartment` | `cancelUnpaidPaymentsForPurpose()` | Удаляет неоплаченные платежи конкретного студента по указанному назначению. |
| `AccountingDepartment` | `settleUnpaidPaymentsForPurpose()` | Отмечает соответствующие неоплаченные платежи студента как оплаченные. |
| `AccountingDepartment` | `totalForPurpose()` | Рассчитывает сумму платежей по назначению с возможностью учитывать только оплаченные записи. |
| `Schedule` | `removeWeeksWithoutLessons()` | Удаляет из расписания недели, в которых нет занятий. |

## Проверка

Проект проверен полной чистой сборкой CMake с C++17, включая `main.cpp`:

```bash
cmake -S . -B build-check -DCMAKE_BUILD_TYPE=Debug
cmake --build build-check --clean-first -j2
```

Также проверен запуск приложения и выход через главное меню. Это не заменяет unit-тесты и измерение покрытия.
